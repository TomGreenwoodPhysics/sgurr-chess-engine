# Third-Party Notices

This file records the third-party software used by the Sgurr web application.
It covers the audited web runtime and browser-test tooling as of 13 July 2026.
The root `LICENSE` applies only to original Sgurr material.

This inventory is a release record, not legal advice. Re-run the dependency
audit and review the resulting obligations whenever dependencies change.

## Browser Runtime

The frontend is plain HTML, CSS, and JavaScript and has no production npm
runtime dependency.

### Visual and audio assets

The web intro image, music, and file-backed sound effects are inventoried in
`THIRD_PARTY_ASSETS.md`. The ordinary board and UI cues are generated by Sgurr
at runtime with the Web Audio API and do not use sampled third-party files.

## Scope Boundary

This notice does not certify every optional desktop, training, benchmarking,
or research dependency in the repository. Audit those separately before
shipping a desktop application or development toolkit. The commercial web
release should contain only the frontend, the allowlisted web media, the
backend runtime, the Sgurr binary/model selected for production, and the
applicable notices.
