How the tree is reduced

Sgurr searches promising lines first.

01

Order the promising moves

Transposition-table moves, good captures, killers, and learned history are tried early so a strong reply can set a useful bound.

02

Prove most moves cheaply

Principal variation search gives the first move a full window. Later moves get a narrow test and earn a full re-search only when they surprise it.

03

Stop hopeless branches

Alpha-beta cutoffs, null move, futility, late-move pruning, and static exchange tests reject lines that cannot change the root decision.

04

Settle noisy leaves

At nominal depth zero, quiescence continues forcing captures and checks so Sgurr does not judge a position in the middle of a tactical sequence.
