How it works

From board to score.

01

Board features

Each piece and square selects one row from a 768-row table.

02

Two views

The selected rows are added into two 384-value arrays. Black's view mirrors the board vertically.

03

Clipping

Values below 0 become 0. Values above 255 become 255.

04

Output

The two arrays use separate output weights. Their order follows the side to move.
