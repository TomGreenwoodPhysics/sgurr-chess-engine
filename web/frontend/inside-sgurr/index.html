Inside Sgurr

Search and evaluation.

Sgurr uses two systems for each move. Search chooses which lines to examine. Evaluation scores the positions at the ends of those lines. The labs below show both systems using the current engine.

01 · Search

Which moves to look at

The complete game tree is too large to examine. Sgurr searches progressively deeper and stops examining branches that cannot improve the current result. Its preferred move can change after each completed depth.

02 · Evaluation

How good a position is

At the end of each line, a small neural network scores the position from its piece-square features. The result is reported in pawns from White's perspective.

03 · Together

One move

Search calls the network millions of times per second. Those scores set bounds, order moves and determine which branches need more work.
