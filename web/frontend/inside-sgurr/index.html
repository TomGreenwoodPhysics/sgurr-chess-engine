What you are seeing

One network, two points of view.

01

Feature transformer

Each occupied piece-square activates one of 768 inputs. The same learned weights build both perspectives.

02

Two accumulators

White and Black each receive 384 integer lanes. A move touches only its changed feature rows; Delta exposes the resulting lane changes.

03

Clipped output

Values are clipped to 0–255, weighted by side to move, and reduced to Sgurr's centipawn score.
