# Sgurr Cave Chamber

`sgurr-cave-chamber.png` was generated specifically for the Sgurr web intro
during the 2026 web UI work using OpenAI image generation. It was not copied
from a third-party asset library.

Before a commercial release, archive the original generation record with the
release paperwork and review the applicable service terms. This note records
provenance; it is not a standalone licence grant.

## Files

- `sgurr-cave-chamber.png`: the archival original, kept for its embedded
  C2PA content credentials (the `caBX` chunk, ~24 KB) recording that the image
  was AI-generated. Not served to browsers. Re-encode the derivatives from
  this file rather than from each other.
- `sgurr-cave-chamber.webp`: what the intro actually loads (WebP q88, 254 KB
  against the PNG's 2,505 KB, PSNR 40.5 dB). Referenced from
  `styles/intro.css` and preloaded in `index.html`.
- `sgurr-social-card.jpg`, 1200x630 Open Graph/Twitter card, cropped around
  the chamber's focal point and given a gentler version of the intro's
  brightness/saturation filter so it stays legible as a thumbnail.

Both derivatives are re-encodes and do **not** carry the C2PA manifest; the
PNG above remains the provenance-bearing copy.
