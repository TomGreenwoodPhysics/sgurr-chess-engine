# Bundled Python Licence Texts

These files were copied without modification from the `.dist-info/licenses`
directories in the Python 3.11 `sgurr-web` environment audited on 13 July 2026.
Package versions are pinned in `web/backend/requirements.lock.txt` and the
licence inventory is in `THIRD_PARTY_NOTICES.md`.

Regenerate this directory from the release environment whenever the lock file
changes. Do not assume that a licence text retained here applies to a different
package version.
